## Validação e uso

Total: 299 jogadores e 4 linhas fallback. Sem nomes duplicados, valores base ausentes ou valores negativos. Todos os registros de entrada foram preservados.
Idade ausente: Kenny Gainwell (RB) e KC Concepcion Jr. (WR). Campos ausentes permanecem nulos.
A ordem dos QBs não é totalmente decrescente no valor base: Aaron Rodgers (11) precede Carson Beck (12). A ordem original foi preservada.
Rankings são calculados por posição e escala, com empates no padrão 1, 2, 2, 4. Não representam um ranking oficial adicional da fonte. source_order registra a sequência original.
As quatro linhas All Other são valores fallback e não jogadores. Foram excluídas dos rankings e das contagens de jogadores.
Value Change foi preservado literalmente. “-”, vazio e “New” não foram convertidos em zero.
Nomes, equipes e idades são os dados fornecidos, sem correções externas. Exemplo para revisão da fonte: Roman Wilson consta com 34 anos. Não tratar esta observação como correção validada.
Os valores não são projeções de pontos. Para comparar trocas, selecionar a escala compatível com a liga. Não misturar SF, TEP e base sem uma metodologia explícita.
